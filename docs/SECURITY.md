# Threat model
The gateway is experimental. Only administrator-controlled upstreams and schemas are supported. OAuth mode validates signed JWT access tokens from an external trusted issuer; configure an issuer that issues access tokens with the exact resource audience. It is not an authorization server and does not forward caller tokens. Upstream service credentials are shared, so subject allowlists are gateway policies, not upstream identity delegation. Never grant writes by default. QuickJS WASM is defense in depth, not a proof of isolation. Run the service as an unprivileged user with OS/container resource limits and network allowlists. Cancellation cannot undo side effects. Do not log code, arguments, tokens or tool results. Subject and tool IDs appear in audit logs; configure retention. External OAuth interoperability and independent penetration testing are required before public deployment.
